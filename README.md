# 💄 Glamora – Beauty & Cosmetics E-Commerce UI/UX Design

## 📌 Project Overview

Glamora is a beauty and cosmetics e-commerce website UI/UX design project created using Figma. It provides users with a modern and visually appealing online shopping experience.

The design focuses on a smooth shopping journey, from exploring beauty products to completing an order through a simple and user-friendly interface.

## ✨ Key Features

- **Home Page:** Showcases beauty products, categories, latest collections, and special offers.
- **Product Details:** Displays product images, descriptions, ratings, pricing, and related products.
- **Shopping Cart:** Allows users to review selected products and check the order summary.
- **Address Page:** Provides an interface to enter and manage delivery details.
- **Payment Page:** Displays payment options and order payment details.
- **Order Confirmation:** Shows successful order placement and confirmation details.
